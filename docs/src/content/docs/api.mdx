The library crates' API documentation, generated by `cargo doc` from the source each time the site deploys. Every public item has a doc comment; CI fails on one without.

| Crate | Role |
| --- | --- |
| [`cantina_dsp`](/api/cantina_dsp/) | Pure audio processing: the `Processor` trait, stock pedals, the pedal format, the drum kit format and sampler. No I/O, no allocation on the audio path. |
| [`cantina_engine`](/api/cantina_engine/) | CoreAudio streams, the real-time graph runtime, transport and tempo map, disk streaming, latency compensation and analysis. |
| [`cantina_hosting`](/api/cantina_hosting/) | Audio Units and CLAP plugins as processors, editor windows and the plugin scanner. |
| [`cantina_project`](/api/cantina_project/) | The project model, commands with inverses, undo history, the file format and the journal. |
| [`cantina_cli`](/api/cantina_cli/) | The `cantina-cli` command: check, render and synthesise without the app; see the [command line](/reference/cli/). |

To build it locally, run `npm run rustdoc` in `docs/` and then `npm run dev`; or run `cargo doc --open` in the repository root.
