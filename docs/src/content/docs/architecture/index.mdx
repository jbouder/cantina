## The ideas everything rests on

- **One abstraction for every pedal.** Stock pedals, pedals you design and third-party plugins all implement the same [`Processor`](/architecture/processor/) trait, so the chain, the mixer, automation, latency compensation and the project file never ask which kind they hold.
- **The audio thread is sacred.** The callback never allocates, locks, blocks or does I/O. Everything reaches it through lock-free queues and atomic graph swaps. See the [real-time rules](/architecture/real-time/).
- **Non-destructive, with one history.** A project is a directory whose audio files are never modified. Every edit is a command with an inverse, so undo, redo and crash recovery are one mechanism. See [project](/architecture/project/).
- **Everything a user makes is JSON.** Pedals, kits, patterns and projects are plain files that people and tools can write.

## Why these choices

| Question | Decision | Why |
| --- | --- | --- |
| Platform | macOS only | CoreAudio gives a round trip of about 5 ms with a class-compliant interface, aggregate devices for free, and one signed DMG to ship. |
| Engine language | Rust | Real-time audio needs no garbage collector, no allocation on the audio thread, and a good lock-free ecosystem. |
| UI | React and TypeScript in Tauri 2 | The visualizer scenes already run in a web view, and Tauri channels carry the binary frames the stage needs. |
| Plugins | Audio Units, then CLAP; no VST3 | AU covers nearly every commercial Mac plugin. CLAP is MIT licensed with a Rust host library. VST3's licence would force the project's. |
| User-made pedals | A node graph over DSP primitives, saved as JSON | Real-time safe by construction, shareable, no compiler. |
| Plugin process model | In process, on the audio thread | What nearly every DAW does. Scanning runs in a child process so a crashing plugin cannot take the app down. |
| Transcription | Basic Pitch on the device, through tract | Finds chords as well as single notes, runs at about 57× real time, and the recording never leaves the machine. See [transcription](/architecture/transcription/). |
| License | MIT | Permissive and simple for contributors, and anyone can reuse the `dsp` crate. |
