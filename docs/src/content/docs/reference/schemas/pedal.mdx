A designed pedal, `<id>.pedal.json`. Node fields depend on the node's kind; the [pedal format](/reference/pedal-format/#kinds) lists every kind and its fields, and explains bindings and the graph rules the schema cannot express.

This page is generated from the schema when the site is built, so it lists
exactly what Cantina accepts. Check a file against it, and the rules beyond
it, with [`cantina-cli check`](/reference/cli/#check).
