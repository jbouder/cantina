What plays along while you practise, as a file of its own,
`<id>.jam.json`. See the [jam format](/reference/jam-format/) for how its
groove, rigs and chords are named, and the [jam guide](/guides/jam/) for
using jams.

This page is generated from the schema when the site is built. The schema
cannot say which grooves, kits and rigs are installed or whether a chord
progression reads; [`cantina-cli check`](/reference/cli/#check) does.
