# Starter cabinet impulse responses

The four `.wav` files here are **synthesised**, not recorded: an
impulse through a speaker-shaped filter (a resonant low cut, a steep
high roll-off, a mid dip and a presence peak), a few close reflections
for the cone and the microphone, and a short dark tail for the box.
They are generated by
`cargo run -p cantina-engine --example make_irs`
(`crates/engine/examples/make_irs.rs`), which is deterministic, and are
Cantina's own work under the MIT license like the rest of the
repository. They are a starting point, not a substitute for a captured
cabinet.

| File | What it is meant to sound like |
| --- | --- |
| `1x12-open-back.wav` | A small open-back combo: light low end, open top |
| `2x12-closed.wav` | A closed two-twelve: fuller lows, a touch darker |
| `4x12-modern.wav` | A closed four-twelve: tight lows, scooped mids, dark top |
| `4x10-bass.wav` | A bass cabinet: deep lows, a bump at 110 Hz, rolled-off top |

## Your own

Drop any mono or stereo `.wav` (stereo is averaged to mono; anything
past three seconds is cut) into `~/Music/Cantina/IRs` and press
**Rescan** on a cabinet pedal. A file there with the same name as a
stock one replaces it. Every file's name is its id, so a project that
refers to `4x12-modern` finds it on another machine with the same file.
